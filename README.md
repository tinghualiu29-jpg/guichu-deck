# 鬼畜 · 中格完整 · 八格回声

公网地址：**https://tinghualiu29-jpg.github.io/guichu-deck/**

中间格按顺序完整播放两段原片，其余八格跟着它的时间走，各自延迟、各自卡顿。

## 打开

**推荐：双击 `打开.command`。** 它会启动本地服务，并自动用默认浏览器打开作品。

也可以直接双击 `index.html`（Chrome / Edge / Safari），但 `media/` 必须和它同级。

打不开时先看这几条：

- 你是不是点了旧的 `localhost:8770` 标签页？那个服务已经停了。用 `打开.command` 重新打开。
- 用 VS Code 内置预览打开本地文件会提示 `Forbidden`，换系统浏览器。
- 只复制了 `index.html`、没带 `media/` 文件夹。
- 第一次运行 `打开.command` 如果被系统拦下：右键 → 打开。
- 页面如果显示 `MEDIA NOT FOUND`，就是 `media/` 没放对位置。

## 播放结构

- **中间格（MASTER）**：素材 A（00:53）→ 素材 B（00:32）顺序播放，从头到尾不剪、不变速、不盖音乐，原声完整。
- **其余八格**：全部静音，各自比中格慢 **0.1–1.0 秒**（每格延迟不同），按各自的节拍做：
  - 卡顿：把当前一小段（约 0.1 秒）连续重放 3–5 次
  - 冻帧：停住 0.3–0.6 秒再继续
  - 变速变声：0.6× / 0.75× / 1.35× / 1.6×，短促地变粗或变尖
- **台词重复**：中格说过的最后一小段会额外回放一次，形成“复读”效果。

所有效果都是每格独立计时，不会八格同时做同一个动作。

## 六个爆发点

按原声能量挑出的重音句位置，底部时间轴上的红色小菱形就是它们：

| 位置 | 画面 |
| --- | --- |
| A 00:02.0 | 餐桌全景，「该问队长了」 |
| A 00:08.75 | 巴基特写，「史蒂夫，你上世纪末带队开心」 |
| A 00:32.0 | 队长与猎鹰，「因为上世纪的人都正常」 |
| B 00:02.75 | 队长站在屋外说话 |
| B 00:18.25 | 三人举杯，「今天那个大桌子」 |
| B 00:23.5 | 队长特写，「是因为在这个旅行中」 |

在这 2.6–3 秒里，八格会**同时卡死 4–6 格**、频繁做 0.5× / 2× 的变声、复读连击，画面加红框并抖动；中间格完全不动，原声继续。

## 操作

| 操作 | 作用 |
| --- | --- |
| 顶部「播放 / 暂停」按钮 | 开始、暂停、继续 |
| `Space` | 同播放 / 暂停 |
| `F` | 全屏 |
| `M` | 静音 / 取消静音 |
| 底部 `↻` | 从头重播 |

暂停时画面、中格原声、八格音频全部停在当前位置，继续时从原处接着播。

## 文件

```

media/a.wav       素材 A 原声（PCM，中格与八格共用）
media/b.wav       素材 B 原声（PCM）
deck-version.html 之前的可调工作台（备份，可删）
editorial-version.html 更早的长文版（备份，可删）
```
